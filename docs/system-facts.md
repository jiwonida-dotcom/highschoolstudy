# 제도 사실 — 2027학년도 고입 · 2030학년도 대입

모든 조언의 전제. 2028 대입개편 이전 제도(9등급제, 수능 선택과목)는 기준으로 쓰지 않는다.

## 1. 고입 — 2027학년도 경기도교육청 내신성적 반영지침

[확인] 김포시는 **비평준화 지역**이다. 중학교 내신으로 고등학교를 선발하므로 운양고 입학 자체가 첫 관문이다.

### 총점 200점 배점

| 영역 | 세부 | 배점 |
|---|---|---|
| 교과활동 | 일반교과 | 120 |
| 교과활동 | 체육·예술 | 30 |
| 비교과 | 출결 | 20 |
| 비교과 | 봉사 | 20 |
| 비교과 | 학교활동 | 10 |
| **합계** | | **200** |

### 일반교과 120점의 학기별 배분

| 시기 | 배점 |
|---|---|
| 중1 2학기 | 12 |
| 중2 (1·2학기) | 48 |
| 중3 (1·2학기) | 60 |

[확인] **2027학년도부터 중1 2학기가 새로 반영된다.**

학기별 점수 = 기본점수 + 성취도 평균점수 + 과목별 취득성적 평균 환산점수

### 지금 통제 가능한 변수 (2026.9 기준)

- [ ] 중3 2학기 중간·기말 성적 (일반교과 약 30점분)
- [ ] 출결 무결점 (20점)
- [ ] 봉사시간 마감 (20점)
- [ ] 학교활동 기록 (10점)

중1 2학기 ~ 중3 1학기 점수는 이미 확정 → 남은 점수 방어가 전략의 전부다.

## 2. 대입 — 2030학년도 (2028 대입개편 적용)

### 고교 내신: 5등급 상대평가 + 절대평가 병기

| 등급 | 상대평가 비율 |
|---|---|
| 1등급 | 상위 10% |
| 2등급 | 누적 34% |
| 3등급 | 누적 66% |
| 4등급 | 누적 90% |
| 5등급 | 나머지 |

- 절대평가 A~E 병기
- 1~3학년 **전 과목 동일** 적용 (공통·선택 구분 없음)

[일반] 학년 약 330명 기준 → 1등급 약 33명, 2등급 누적 약 112명. 학급당 인원과 학년 정원은 학교알리미에서 매년 재확인.

### 수능: 선택과목 없는 통합형

국어 · 수학 · 영어 · 한국사 · 탐구(통합사회 + 통합과학) · 제2외국어

### 고교학점제 전면 시행

- 3년간 **192학점**
- 2학년부터 선택과목은 학생이 직접 설계
- 1학년 공통과목(국어·수학·영어·통합사회·통합과학·한국사)이 곧 대입 내신 → **고1 1학기 중간고사부터 대입 시작**

## 3. 내신 관리 2단계

### (a) 지금 ~ 2027.2 — 고입 200점 방어
중3 2학기 지필 대비, 출결, 봉사시간. 위 체크리스트 참고.

### (b) 2027.3 ~ — 5등급제 전략
1. 학기 초 **평가계획서**로 수행평가 비율·항목을 먼저 확보한다.
2. 지필보다 **수행을 먼저** 챙긴다 (수행은 만점이 가능하고 일정이 미리 공개된다).
3. 시험 4주 전 역산 계획을 세운다.

## 4. 자기주도 학습 필수 체계

- 주간 계획표 (요일 × 과목)
- 인강 '보기'와 '풀기' 분리: 문제 먼저 → 해설 강의 → 강의 후 백지 복기
- 오답노트
- 주 1회 자가 점검 리포트
- 시험 4주 전 역산 계획

관리자 부재 보완 장치: 학부모 주 1회 점검 / 코치와 주간 대화 / 주말 셀프 테스트

인강·자습으로 해결이 어려운 지점: 수학 서술형 첨삭, 영어 쓰기 피드백 → 그 지점만 별도 대안 필요
