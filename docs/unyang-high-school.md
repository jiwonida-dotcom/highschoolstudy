# 운양고 특징 정리 및 입학 전 확인 체크리스트

작성 2026-09-13

## [확인] 공식·언론 보도로 확인된 사실

- 2013년 개교, 공립 남녀공학 일반계고, 김포시 운양동(김포한강11로 58)
- 약 30학급, 학생 약 1,000명(학급당 약 33명), 교직원 약 68명 (2023~2025 공시 기준 → 학교알리미 재확인 필요)
- 고교학점제: 매년 5월 '교육과정 박람회' 개최. 2·3학년 '교육과정 리더'가 과목 부스에서 후배에게 과목 특징·연계 학과·공부 팁 안내, 선택과목 안내 책자 배포 (2025.5.22 김포신문)
- 운양고·장기고·김포제일고 3교 연합 공동교육과정, 온·오프라인 강좌, 소인수 과목(무학년제) 운영 (2024.11 입학설명회 보도)
- 특색 프로그램: 자율교육과정(16+1), 과학 행사·천체관측 캠프·독서활동, 탐구실천 발표회, 데이터 사이언스 캠프
- 신입생 입학설명회를 매년 11월경 개최 (2024.11.21, 400명 이상 참석)
- 2026학년도 입학식: 3월 3일, 반 배정은 2월 27일 홈페이지 공개, 리로스쿨 사전 로그인 필요
- 연중 행사: 과학의 날(4월), 체육대회(5월), 1학년 수련회(10~11월), 2학년 수학여행, 탐구 실천 발표대회, 동아리 발표대회(12월)
- 교육과정 편제표·과목선택 안내를 홈페이지 교육과정 게시판에 공개 (2022 개정 교육과정 적용 편제표 있음)

## [추정] 직접 확인 필요

- 4년제 진학률 51.8%, 전문대 17.3% (부동산 정보 사이트 집계, 연도 미확인)
- "무난한 일반고", 최상위권 쏠림이 덜해 내신 경쟁이 완만하다는 인식 (커뮤니티 수준)
- 고입 커트라인은 매년 변동, 수치 단정 불가

## 선생님 정보에 대한 원칙

개별 교사 정보는 공개 자료로 확인할 수 없다. 지어내지 않는다. 대신:

1. 입학 후 첫 2주 관찰 체크리스트
   - [ ] 시험 문제 출처 — 교과서 / 프린트 / 부교재 중 어디서 나오는가
   - [ ] 수행평가 비중과 채점 기준의 구체성
   - [ ] 질문에 대한 반응 (수업 후 질문이 가능한가)
   - [ ] 필기 방식 (판서 / PPT / 학습지)
2. 교육과정 리더·선배에게 물을 질문 (5월 교육과정 박람회 활용)
3. 평가계획서와 학교알리미 교원 현황 읽는 법

## 입학 전 확인 체크리스트

### 학교 홈페이지 (gpoe.kr/unyang-h)
- [ ] 2027학년도 신입생 입학설명회 일정(11월 예상) — 참석
- [ ] 2022 개정 교육과정 적용 편제표: 1학년 공통과목 구성, 2·3학년 선택과목 목록
- [ ] 2026년 교육과정 박람회 자료·선택과목 안내 책자
- [ ] 2026학년도 1학년 평가계획서(지필·수행 비율, 수행평가 항목)
- [ ] 학교 교육계획서: 연간 행사, 자율교육과정(16+1), 공동교육과정 운영 방식
- [ ] 입학 관련 공지: 반 배정 발표일, 교복, 리로스쿨 가입, 교과서 배부
- [ ] 동아리 목록과 모집 시기

### 학교알리미 (schoolinfo.go.kr)
- [ ] 2026년 학급수·학생수(학년별) → 1등급 10% 인원 규모 계산
- [ ] 교원 현황(과목별 교사 수)
- [ ] 교과별 학업성취도 분포(성취도 A~E 비율)
- [ ] 졸업생 진로 현황(4년제·전문대·기타) — 부동산 사이트 수치 대조
- [ ] 학교 교육과정 편성 운영 현황
- [ ] 학교폭력 실태·학생 1인당 교육비 등 기본 공시

### 김포교육지원청 (gpoe.kr)
- [ ] 2027학년도 고등학교 입학전형 기본계획(비평준화 지역 전형 일정·원서접수일)
- [ ] 내신성적 반영지침 최종본(200점 배점 확인)
- [ ] 관내 고교 종합현황(학교별 모집정원)
- [ ] 고입 원서접수 절차·필요 서류

### 중학교(담임·진로 선생님)
- [ ] 현재 고입 내신 산출 점수(중1 2학기·중2·중3 1학기) 조회
- [ ] 출결·봉사시간 현황과 마감 기한
- [ ] 전년도 운양고 지원자 성적대(학교 내부 참고자료)
