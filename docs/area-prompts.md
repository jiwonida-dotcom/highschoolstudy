# 영역별 시작 프롬프트

첫 대화 뒤에 이어서 보내는 문장입니다.

## 1. 운양고의 특징

```
운양고의 특징을 [확인]과 [추정]으로 구분해서 정리해 줘. 그리고 입학 전에 내가 학교 홈페이지·학교알리미·김포교육지원청에서 직접 확인해야 할 항목을 체크리스트로 만들어 줘.
```

## 2. 내신 관리 방법

```
2030학년도 대입 5등급제 기준으로, 고1 1학기 중간고사까지 12주 내신 준비 계획을 주차별 표로 짜 줘. 인강과 자습 위주이고, 수행평가를 먼저 챙기는 순서로.
```

## 3. 선생님들 특징

```
입학 후 첫 2주 동안 과목별 선생님의 수업·평가 스타일을 파악하는 관찰 체크리스트와, 교육과정 리더나 선배에게 물어볼 질문 10개를 만들어 줘.
```

## 4. 학습 시 필요한 사항

```
학원 없이 인강+자습으로 공부하는 중3이 빠지기 쉬운 함정 5가지와, 각각을 막는 주간 루틴을 제안해 줘. 학부모가 주 1회 점검할 항목도 같이.
```

## 급한 질문

```
중3 2학기 중간·기말이 고입 200점 중 몇 점에 해당하는지, 지금 성적으로 운양고 지원에 문제가 없는지 계산해 줘
```
