# 첫 대화 템플릿

프로젝트에서 첫 메시지로 보내는 내용입니다. 빈칸을 채울수록 첫 답변이 구체적입니다. 모르는 항목은 '미정'이라고 적으면 됩니다.

```
[기본 정보]
- 현재 학교 / 학급 인원:
- 중3 1학기 성적 (과목별 성취도 A~E 또는 점수): 국어 / 수학 / 영어 / 사회 / 과학 / 역사 / 기타
- 중2 성적 (대략):
- 출결 (결석·지각·조퇴 횟수):
- 봉사시간 누계:

[학습 현황]
- 수강 중인 인강 (사이트·강사·과목·진도):
- 하루 순공 시간 (평일 / 주말):
- 가장 약한 과목과 그 이유:
- 선행 진도 (수학: 공통수학1까지? 영어: 고1 수준?):
- 학원을 그만둔 뒤 달라진 점 (좋아진 것 / 어려워진 것):

[목표]
- 운양고를 지원하는 이유:
- 관심 진로·계열 (모르면 '미정'):
- 희망 대학 수준 (대략):

[요청]
위 정보를 바탕으로 (1) 고입까지 남은 기간의 우선순위, (2) 입학 전 겨울방학 계획, (3) 고1 1학기 내신 준비 순서를 알려줘. 정보가 부족한 부분은 한 번에 하나씩 물어봐 줘.
```
